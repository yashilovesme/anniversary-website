# Background Music Directory

Place your background music here to add ambient sound to the website.

## Music File

Save your audio file as:
- `anniversary.mp3`

## Audio Specifications

**Recommended Format:** MP3
- **Bitrate:** 128-192 kbps (balance between quality and file size)
- **Sample Rate:** 44.1 kHz
- **Duration:** 60-120 seconds (longer tracks will loop)
- **Volume:** Normalized to -3dB to prevent distortion

**Alternative Formats Supported:**
- WAV
- OGG
- M4A

## How to Add Music

1. Prepare or download a royalty-free background music track
2. Convert to MP3 format if needed
3. Save as `anniversary.mp3` in this directory
4. The website will automatically detect and load it
5. A music button (♫) will appear in the top-right corner

## Recommended Music Styles

- Soft piano
- Ambient/relaxing
- Lo-fi beats
- Indie/folk acoustic
- Romantic instrumental
- String ensemble

## Music Button Features

- Only plays when user clicks the button (autoplay is blocked by browsers)
- Button toggles play/pause
- If music file is missing, button auto-hides
- Works on all modern browsers

## Royalty-Free Music Sources

Some great places to find free background music:
- YouTube Audio Library
- Unsplash Music
- Free Music Archive
- Epidemic Sound (free tier)
- Pixabay Music
- Pexels Music

## Performance Note

A typical 60-second MP3 is about 500KB-1MB in size. This won't significantly impact load times.

## Example Track Specifications

For a perfect anniversary atmosphere:
- Gentle piano or strings
- No sudden loud sections
- Smooth, continuous melody
- Calm and romantic tone
- 60-90 seconds recommended

---

**If no music file is provided, the website works perfectly without it!**
