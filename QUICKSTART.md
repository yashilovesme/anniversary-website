## 🚀 Quick Start (3 Steps)

### Step 1: Add Photos
1. Place 4 photos in `assets/photos/` folder
2. Name them: `photo1.png`, `photo2.png`, `photo3.png`, `photo4.png`
3. Photos will automatically display as beautiful stickers!

### Step 2: (Optional) Add Music
1. Find a 60-120 second MP3 audio file
2. Save it as `assets/music/anniversary.mp3`
3. A music button will automatically appear

### Step 3: Deploy
**Best option: GitHub Pages (FREE & Easy)**
1. Go to Repository Settings
2. Enable GitHub Pages
3. Select "main" branch
4. Your site is live at: `https://yashilovesme.github.io/anniversary-website`

## 🎯 Easy Customization

### Change Names & Messages
Edit `js/main.js`:
```javascript
const anniversaryConfig = {
    person1: "Saksham",
    person2: "Yashica",
    anniversaryDate: "2026-09-01T00:20:00",
    // ... edit photos and timeline items
};
```

### Change Colors
Edit `css/style.css`:
```css
:root {
    --primary-pink: #FFB6D9;
    --rose-pink: #FF69B4;
    /* ... customize all colors */
}
```

### Change Text
- Edit `index.html` for HTML text
- Edit `js/main.js` for JavaScript messages
- Edit `js/games.js` for game messages

## 🚨 Troubleshooting

### Photos Not Loading?
- Check filenames: `photo1.png`, `photo2.png`, etc.
- Ensure files are in `assets/photos/` folder
- Try refreshing the page
- Check browser console (F12 → Console)

### Games Not Working?
- Refresh the page
- Ensure JavaScript is enabled
- Clear browser cache
- Try different browser

### Music Not Playing?
- Click the music button (♫) in top-right
- Check phone/computer volume
- Ensure MP3 file exists in `assets/music/`
- Some networks block audio - try Wi-Fi

### Not Responsive on Mobile?
- Try landscape orientation
- Refresh the page
- Check viewport settings in browser
- Try different browser
